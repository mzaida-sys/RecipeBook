# RecipeBook

RecipeBook is a mobile Android application designed for food enthusiasts to discover, share, and manage cooking recipes in real time.

## Features

- User Authentication: Secure user registration and login.
- Recipe Discovery: Browse various recipes with images and step-by-step instructions.
- Add New Recipes: Users can publish their own recipes with ingredients and photos.
- Search & Filter: Search for specific recipes by title or category.
- Favorites: Save preferred recipes for quick access.

## Tech Stack & Tools

- Programming Language: Java
- Development Environment: Android Studio
- Backend & Cloud Services:
  - Firebase Authentication
  - Firebase Realtime Database / Cloud Firestore
  - Firebase Storage
- User Interface:
  - Material Design Components
  - RecyclerView and CardView
  - XML Layouts

## How to Run the Project

1. Clone this repository:
   git clone https://github.com/mzaida-sys/RecipeBook.git

2. Open the project using Android Studio.

3. Place your valid google-services.json file inside the app/ directory to connect Firebase.

4. Sync Gradle files with the project.

5. Build and run the application on an Android Emulator or a connected physical device.
